### 제안 목적

행정사법인 정유는 기업컨설팅, 개발행위 인허가, 토지보상, 고충민원, 행정심판 등 전문 행정 서비스를 제공하는 경기 수원 소재 법인입니다.

본 제안서는 **신뢰 기반 전문가 홈페이지**로서 다음 3가지 목적을 달성하기 위해 구축된 결과물을 정리합니다.

1. **신규 고객 유입** — 검색 노출 최적화(SEO)를 통한 온라인 집객
2. **상담 전환율 제고** — 무료 상담 신청 폼을 통한 리드 수집 자동화
3. **법인 브랜드 신뢰도 강화** — 전문성·실적·팀을 시각적으로 전달

## 2. 고객사 현황 및 과제

### 기존 문제점

| 구분 | 문제 |
|------|------|
| 온라인 접점 | 홈페이지 부재로 검색 시 법인 정보 확인 불가 |
| 상담 유입 | 전화 외 상담 채널 없어 비업무 시간 문의 누락 |
| 신뢰 표현 | 실적·팀 구성·프로세스를 시각화한 자료 없음 |
| 경쟁 대비 | 동종 법인 대비 디지털 존재감 열위 |

### 해결 방향

```
검색 유입 → 신뢰 형성 → 상담 신청 → DB 저장 → 담당자 연락
```

고객이 검색으로 유입된 후 **법인 소개 → 실적 → 팀 신뢰 → 상담 신청**까지 한 페이지에서 완결되는 전환 최적화 구조를 설계했습니다.

## 3. 구축 결과물 상세

### 3-1. 페이지 구성

| 섹션 | 내용 | 전환 목적 |
|------|------|-----------|
| 히어로 | 슬로건 + 핵심 통계 4개 + CTA 버튼 | 첫인상, 즉시 상담 유도 |
| 신뢰 지표 | 누적 처리 건수·만족률·기업 고객 수·해결률 | 숫자로 신뢰 구축 |
| 업무 분야 | 기업컨설팅·인허가·토지보상·고충민원·행정심판 5개 카드 | 서비스 명확화 |
| 팀 소개 | 대표·소속 행정사 2인 프로필 | 전문가 신뢰 |
| 진행 절차 | 상담 접수 → 사안 검토 → 전략 수립 → 기관 대응 → 결과 도출 5단계 | 불안 해소 |
| 성공 사례 | 행정심판 2건·토지보상·인허가 실제 사례 | 실적 증명 |
| 고객 후기 | 별점 6건 (4.98/5.0 평균) | 사회적 증거 |
| 상담 문의 | 이름·연락처·서비스·내용 입력 폼 (DB 저장) | 리드 수집 |
| 오시는 길 | 지도 임베드 + 교통편 안내 | 오프라인 방문 유도 |

### 3-2. 주요 기능

**📋 상담 문의 폼 (Supabase 연동)**
- 입력 유효성 검사 (이름·연락처 필수)
- 제출 시 Supabase PostgreSQL `contacts` 테이블 자동 저장
- 성공/실패 피드백 UI 표시
- 관리자 메모·처리 상태 컬럼 사전 구성 (`신규` → `상담중` → `완료`)

**📱 반응형 레이아웃**
- 모바일·태블릿·PC 3단계 완전 대응
- 모바일 하단 고정 CTA 바 (전화 / 카카오톡 / 무료상담 신청)
- 모바일 드로어 메뉴

**✨ 애니메이션 & UX**
- 스크롤 트리거 섹션 진입 애니메이션 (6가지 방향)
- 숫자 카운팅 애니메이션 (신뢰 지표)
- 헤더 스크롤 투명 → 흰색 전환

**🔍 SEO 최적화**
- 타이틀·메타 디스크립션·키워드 태그
- Open Graph (SNS 공유) 태그
- schema.org `LocalBusiness` 구조화 데이터 (JSON-LD)
- `robots.txt` 크롤러 설정

**⚖️ 법적 준수**
- 개인정보처리방침 전용 페이지 (`/privacy`) — 개인정보보호법 제30조

## 4. 기술 구성

### 기술 스택

| 분류 | 기술 | 선택 이유 |
|------|------|-----------|
| 프레임워크 | React 18 + Vite | 빠른 빌드, 컴포넌트 재사용 |
| 스타일 | TailwindCSS 3 | 일관된 브랜드 컬러 시스템 |
| 애니메이션 | Framer Motion 11 | 자연스러운 스크롤 효과 |
| 아이콘 | Lucide React | 경량 SVG 아이콘 |
| 라우팅 | React Router DOM 7 | SPA 다중 페이지 지원 |
| DB / 백엔드 | Supabase (PostgreSQL + RLS) | 무서버, 실시간, 보안 RLS 정책 |
| 폰트 | Pretendard Variable | 한글 전문 폰트, CDN 제공 |
| 배포 | Vercel | 자동 HTTPS, CDN, 무중단 배포 |

### 브랜드 컬러

| 이름 | HEX | 용도 |
|------|-----|------|
| Primary | `#0F5B57` | 메인 CTA, 버튼, 아이콘 |
| Primary Dark | `#031a18` | 다크 섹션 배경 |
| Gold | `#C9A84C` | 강조 텍스트, 프리미엄 포인트 |

### 보안 설계

- Supabase Row Level Security(RLS) — 인증 없는 외부 직접 조회 차단
- 폼 입력 유효성 검사 — 클라이언트 측 1차 검증
- 환경변수 분리 — API 키 코드베이스 미포함 (`.gitignore`)
- HTTPS 강제 적용 — Vercel 자동 SSL

## 6. 운영 가이드

### 콘텐츠 수정 방법

모든 텍스트 데이터는 `src/data/` 및 `src/constants/` 폴더에 분리되어 있어 코드 수정 없이 내용 교체가 가능합니다.

| 수정 항목 | 파일 경로 |
|-----------|-----------|
| 회사 전화·이메일·주소·카카오 URL | `src/constants/contact.js` |
| 신뢰 지표 숫자 | `src/data/metrics.js` |
| 업무 분야 카드 | `src/data/services.js` |
| 팀 소개 및 경력 | `src/data/team.js` |
| 성공 사례 | `src/data/cases.js` |
| 고객 후기 | `src/data/testimonials.js` |

### 상담 문의 확인 방법

1. [Supabase 대시보드](https://supabase.com) 로그인
2. `Table Editor` → `contacts` 테이블 선택
3. 신규 행 = 새 상담 신청 (컬럼: 이름·연락처·서비스·내용·접수일시·처리상태)

### 배포 방법

내용 수정 후 재배포:
```bash
vercel --prod
```
